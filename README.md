# Secure-File-Checker
The Secure File Checker is a web-based application designed to enhance user safety by identifying potentially harmful files before they are uploaded or used. In many real-world scenarios, users unknowingly upload or download files that may contain malicious content, leading to security risks.
# 🔐 Secure File Checker

## 🚨 Problem
Users may unknowingly upload harmful or malicious files.

## 💡 Solution
This project checks uploaded files for suspicious extensions and alerts users.

## ⚙️ Features
- File upload system
- Malware detection (basic)
- Instant result (Safe / Suspicious)

## 🛠 Tech Stack
- Node.js
- Express.js
- Multer
- HTML, CSS, JavaScript

## ▶️ How to Run

### Backend
cd backend  
npm install  
node server.js  

### Frontend
Open frontend/index.html in browser
